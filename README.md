# Fish Sort – website

Static site for **Fish Sort: Ocean Color Puzzle** (`com.nex.fishsort`) by nexS.

- `/app-ads.txt` – AdMob authorized sellers file
- `/` – landing page
- `/privacy-policy` – Privacy Policy
- `/terms` – Terms of Use

## Deploy (Cloudflare Pages)
Connect this repo in Cloudflare Pages with **no build command** and output directory `/` (root).
`_headers` makes `app-ads.txt` serve as `text/plain`.
